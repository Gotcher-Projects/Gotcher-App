# S5.44 — Theme Polish & Layout Fidelity Fix

**Status: Needs Verification**
**Branch:** journal-updates
**Depends on:** S5.41, S5.42 (implemented, Needs Verification → now expanded)

---

## Overview

Four fixes discovered during S5.41/S5.42 verification:

1. **Theme saves fail silently** — backend `VALID_THEMES` still has old keys (`garden/dusk/blush`); any theme other than `classic` returns 400, silently reverted by the optimistic-update pattern.
2. **Theme picker undersells the themes** — current pill buttons don't visually preview the theme. Replace with theme cards: bg swatch + accent bar + label.
3. **Editor ≠ published view** — font size = `cs * 0.025` where `cs` is the ResizeObserver-measured container width. Editor on mobile (cs ≈ 350 → 8.75px) vs published view on desktop (cs ≈ 576 → 14.4px) produce completely different text wrapping. Fix: virtual canvas at fixed `CANVAS_SIZE = 500`, CSS-scaled to fit each container.
4. **Only 3 fonts** — user wants Playfair Display, Merriweather, Nunito, and Lato added.

## Changes

### 1. Backend — BabyProfileService.java
Update `VALID_THEMES`:
```java
private static final Set<String> VALID_THEMES = Set.of("classic", "coral", "midnight", "meadow");
```

### 2. StorybookTab.jsx — theme picker + error handling
- Replace pill buttons with theme cards (bg fill + accent bar + label + selected ring)
- Fix `handleThemeSelect` to save previous key and revert on API failure

### 3. index.html — Google Fonts
Add Lato (400), Merriweather (400), Nunito (400+600), Playfair Display (400+700) to the existing font URL.

### 4. tailwind.config.js — fontFamily
Add `playf`, `merri`, `nunito`, `lato` font entries.

### 5. LayoutEditor.jsx + LayoutRenderer.jsx — virtual canvas + 7 fonts
Both:
- Define `const CANVAS_SIZE = 500;`
- Compute `scale = containerSize / CANVAS_SIZE`
- Inner canvas: fixed 500×500px div with `transform: scale(scale) / transformOrigin: top left`
- Outer container: `max-w-[500px]` with `overflow: hidden` and `aspectRatio: 1/1`
- Update `FONT_MAP` to 7 entries: serif, playf, merri, sans, lato, nunito, display

LayoutEditor additionally:
- `cs = CANVAS_SIZE` (constant) — all Rnd positions use this
- Add `scale={scale}` to each `<Rnd>` so drag/resize maps correctly to canvas coords
- Update `FONT_OPTIONS` to 7 entries for the picker UI
