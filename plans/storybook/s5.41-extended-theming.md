# S5.41 — Extended Book Theming

**Status: Needs Verification**
**Branch:** journal-updates
**Depends on:** S5.4 (base book theming — complete)

## Overview

S5.4 laid the foundation: `bookThemes.js` with 4 presets, a theme picker in StorybookTab, and `LayoutRenderer` already consuming `theme.fontClass` and `theme.bg`. This session replaces the 4 desaturated "flesh tone" themes with more distinctive options drawn from the CradleHQ brand palette, and wires up the remaining hardcoded theming surfaces (drop-cap color, published chapter bg, divider ornament, editor text font).

---

## New Theme Definitions

Replace all 4 themes in `Frontend/src/lib/bookThemes.js`:

| Key | Label | bg | accent | fontClass | dividerChar | textColor | isDark |
|---|---|---|---|---|---|---|---|
| `classic` | Classic | `#fdf9f2` | `#9b7e5a` | `font-serif` | `◆` | — | — |
| `coral` | Coral | `#fff3f1` | `#e06c5f` | `font-serif` | `♡` | — | — |
| `midnight` | Midnight | `#1e2040` | `#a0a8c8` | `font-sans` | `·` | `#e8eaf6` | `true` |
| `meadow` | Meadow | `#edf4ed` | `#4a7a4a` | `font-sans` | `✿` | — | — |

New fields on the theme shape:
- `dividerChar` — ornament character in the published chapter header. *(May be removed in a future polish pass — don't invest heavily in this.)*
- `textColor` — explicit text color for dark themes; `undefined` for light themes (Tailwind class applies normally)
- `isDark` — boolean for dark-background themes

Palettes (5 shades, bg → deeper accent direction):

## Changes Per File

### `Frontend/src/index.css`

Change `book-chapter-first::first-letter` color:

```css
/* Before */
color: hsl(var(--color-highlight));

/* After */
color: var(--book-accent, hsl(var(--color-highlight)));
```

This decouples the drop-cap from the app UI theme. Setting `--book-accent` on a parent container makes the book theme accent win.

---

### `Frontend/src/components/tabs/StorybookTab.jsx`

In the published `ChapterCard` (currently around lines 392–450):

1. **Chapter container `div`** — currently has `bg-[#fdf9f2]` hardcoded:
   - Remove `bg-[#fdf9f2]` Tailwind class
   - Add `style={{ '--book-accent': theme?.accent, backgroundColor: theme?.bg || '#fdf9f2' }}`

2. **Divider block** (currently lines ~398–402):
   - Replace hardcoded `◆` with `{theme?.dividerChar || '◆'}`
   - Replace `bg-color-highlight/25` on divider lines with inline `style={{ backgroundColor: theme?.accent, opacity: 0.25 }}`
   - Replace `text-color-highlight/50` on ornament span with inline `style={{ color: theme?.accent, opacity: 0.5 }}`

3. **Body text container** (non-layout published view):
   - Wrap prose in a container with `style={{ color: theme?.textColor }}`. Inline style overrides `text-foreground/85` only when `textColor` is set (Midnight). Light themes have `undefined` so nothing changes.

4. **`renderPublishedBody` call** (currently around line 431):
   - Add `theme` as last argument: `renderPublishedBody(chapter.body, chapter.photoOverrides, journalEntries, firsts, theme)`
