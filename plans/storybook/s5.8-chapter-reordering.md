# S5.8 — Chapter Reordering

**Status: Not Started**
**Branch:** journal-updates
**Depends on:** S5.3+ (any layout-stable session)

---

## Overview

Chapters currently display in creation order. Default sort is chronological (by baby age / period start week), but users can manually reorder them. An `order_index` column on chapters drives the display order — null means "use chronological default."

---

## Default Sort

When no `order_index` is set (all null), sort chapters by:
1. `period_start_weeks ASC` for period chapters
2. `created_at ASC` as tiebreaker

Once a user manually reorders, explicit `order_index` values are written for all chapters and that order is used going forward.

---

## Backend Changes

### V34__chapter_order_index.sql
```sql
ALTER TABLE chapters ADD COLUMN order_index INT;
```

### StorybookService.java
- `getChapters()`: sort by `order_index ASC NULLS LAST`, then `period_start_weeks ASC`, then `created_at ASC`
- New `reorderChapters(long babyProfileId, List<Long> orderedIds, long userId)`: writes `order_index` 0…N-1 in the given order, ownership check

### StorybookController.java
```
PUT /storybook/order   body: { "orderedIds": [3, 1, 5, 2] }
```
Auth-protected. Calls `reorderChapters`.

---

## Frontend Changes

### StorybookTab.jsx
- Add drag-to-reorder to the chapter list (use `@dnd-kit/sortable` — already likely in project, or install)
- Each `ChapterCard` gets a drag handle (grip icon, visible on hover)
- On drop: fire `PUT /storybook/order` with new order
- Optimistic update: reorder the local list immediately, revert on error

### Install (if not present)
```
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

## Verification

- Chapters display in age order by default
- Drag chapter 3 to position 1 → list updates immediately
- Reload → new order persists
- Creating a new chapter appends it at the end of the current order
