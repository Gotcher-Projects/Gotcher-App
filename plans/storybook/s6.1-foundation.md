## Context

S6 redesigns storybook authoring so the wizard is the primary tool and templates are the source of truth. This session lays the data and template foundation that S6.2 (wizard UI) and S6.3 (auto-gen) build on.

Three goals:
1. Store AI-generated content per memory in a dedicated JSONB column (`generated_content`), keyed by `sourceKey` — survives template switches, page restructuring, and multiple wizard runs
2. Expand AI output to produce `title` and `caption` alongside the existing `body` and `pullQuote`
3. Add slot contract metadata to all templates (existing + new) so the wizard knows how to fill them automatically

No wizard UI changes this session. No layout editor changes beyond template definitions.

## Frontend — Template Definitions

**7. `LayoutEditor.jsx`** — update all template objects to add slot contract metadata and `contentSource` per block.

### New metadata fields on each template
```js
{
  id: '...',
  label: '...',
  memoryCount: 1,    // memories this template holds (0 = photo-only pages)
  minPhotos: 0,      // minimum photos needed to use this template
  maxPhotos: 1,      // photo slots in the template
}
```

### New field on each block definition
```js
contentSource: { memoryIndex: 0, piece: 'body' }   // for text blocks
contentSource: { memoryIndex: 0, photoIndex: 0 }   // for photo blocks
// photoIndex is relative to that memory's available photos
// photo-only templates: contentSource: { photoIndex: 0 } (no memoryIndex)
```

### Update existing 5 templates
- `classic`: memoryCount=1, minPhotos=0, maxPhotos=1 — text→`{memoryIndex:0, piece:'body'}`, photo→`{memoryIndex:0, photoIndex:0}`
- `side-by-side`: memoryCount=1, minPhotos=0, maxPhotos=1 — same as classic
- `hero`: memoryCount=1, minPhotos=1, maxPhotos=1 — text→`{memoryIndex:0, piece:'caption'}`, photo→`{memoryIndex:0, photoIndex:0}`
- `gallery`: memoryCount=1, minPhotos=2, maxPhotos=2 — text→`{memoryIndex:0, piece:'body'}`, photo-1→`photoIndex:0`, photo-2→`photoIndex:1`
- `text-only`: memoryCount=1, minPhotos=0, maxPhotos=0 — text→`{memoryIndex:0, piece:'body'}`
