## S5.7 — Book Cover

### What changed
- New `BookCover` component appears at the top of the Book tab (above theme picker).
- Shows baby's name + subtitle, with an optional hero photo.
- Subtitle defaults to "A memory book · Born [birthdate]" and is editable inline.
- Cover photo can be uploaded (3:4 crop); falls back to placeholder if none set.

### Test steps

**Initial state:**
- [ ] Navigate to Memories → Book.
- [ ] BookCover card appears at top, shows "[name]'s Memory Book" and the default subtitle.
- [ ] The placeholder photo area shows a camera icon (no photo yet).

**Subtitle editing:**
- [ ] Click the subtitle text. An input field appears with the current text.
- [ ] Edit it, press Enter (or click ✓). The new subtitle saves.
- [ ] Reload the page — the edited subtitle persists (stored in DB).
- [ ] Press Escape to cancel without saving — subtitle reverts.

**Cover photo:**
- [ ] Click "Add photo" in the cover card.
- [ ] Choose a photo and crop it (3:4 ratio).
- [ ] Cover card shows the uploaded photo.
- [ ] "Add photo" button changes to "Change".
- [ ] Reload — photo persists.

**Theme integration:**
- [ ] Switch book themes — the BookCover background, text color, and divider color update with the theme.

## S5.8 — Chapter Reordering

### What changed
- Chapter list in the Book tab supports drag-to-reorder.
- Each chapter card has a grip icon (⠿) on the left edge.
- Dragging saves the new order to the backend immediately (optimistic update — reverts on failure).
- Sort is persisted via the existing `sort_order` column.

### Test steps

**Prerequisite:** At least 2 published or draft chapters.

**Basic drag:**
- [ ] Hover over a chapter card — a grip icon appears on the left side.
- [ ] Drag the top chapter below the second one.
- [ ] The list reorders immediately (optimistic update).
- [ ] Reload the page — the new order persists.

**Multiple reorders:**
- [ ] Drag the bottom chapter to the top.
- [ ] Reload — order persists again.

**Error handling (optional):**
- [ ] Disable network (DevTools offline mode), drag a chapter.
- [ ] An error toast appears and the list snaps back to its previous order.

**New chapter append:**
- [ ] Create a new chapter after reordering.
- [ ] It appears at the end of the list (new chapters have no `sort_order`, so they sort last by `created_at`).

## S5.9 — PDF Export

### What changed
- "Download PDF" button appears in the Book tab header (next to the theme picker) when there is at least one published chapter.
- Clicking it captures each page of each published chapter via html2canvas and assembles a jsPDF document (3:4 pages, 150×200mm).
- The PDF is saved as `[baby-name]-storybook.pdf`.

### Test steps

**Button visibility:**
- [ ] With no published chapters, the "Download PDF" button is hidden.
- [ ] Publish a chapter — the button appears.

**Basic export:**
- [ ] Click "Download PDF". Button shows a spinner and "Exporting…".
- [ ] A PDF file downloads automatically after a few seconds.
- [ ] Open the PDF. Each published chapter's pages appear, one per PDF page.

**Visual fidelity:**
- [ ] Theme background color matches the on-screen view.
- [ ] Text content is readable and roughly matches the on-screen layout.
- [ ] Photos appear in the PDF (requires CORS-permissive Cloudinary images — should be fine).

**Multi-page chapters:**
- [ ] If you have a chapter with multiple layout pages (v2), all pages appear as separate PDF pages.

**Empty / edge cases:**
- [ ] If a chapter is in draft status, it does NOT appear in the PDF.
- [ ] Classic (non-layout) chapters render as a simple text page with chapter title and body.

**Known limitations (acceptable for now):**
- Sticker decorations are not rendered in the PDF (html2canvas doesn't support CSS mask-image).
- Text may not perfectly fit blocks (html2canvas captures at base font size, not the fitted size).
- Very long chapters may clip text that overflows the block area.
