# S6.4 — Scrapbooking Direction & Decisions (north star)

**Status: Decisions made → implemented across S7–S10**
**Depends on:** S6.1–S6.3 complete and verified

---

## What this doc is

S6.4 started as a discussion of ways to improve scrapbooking. Out of it came a clear product
direction that the S6.1–6.3 architecture doesn't yet match. This doc records those **decisions**.
The implementation is sequenced across four sessions — see `s7-builder-shell.md`,
`s8-builder-placement.md`, `s9-builder-editing.md`, `s10-cutover.md`.

The Quick Build preview reference mock lives at `s6.4-grouping-mockup.html` (interactive).

---

## Decisions

1. **Generate-first ordering.** Generate the AI text *before* arranging. The user places finished
   content onto pages — content is never blocked behind layout choices.

2. **A unified Scrapbook Builder replaces the LayoutEditor.** The current free drag-resize canvas
   feels like a cheap product. The replacement uses **fixed template slots** — pick a page
   template, fill its slots with memories and photos. No free resize. Deliberately fewer knobs,
   done well, over a do-everything tool that feels shoddy.

3. **Consolidate on the page model — remove "One Story."** Every chapter is page-based. Two entry
   paths remain, both converging on the same builder:
   - **Quick Build (auto):** generate → auto-arrange → preview → "modify" opens the builder
   - **Scrapbook (guided):** generate → open the builder seeded with a suggested arrangement
   The single-narrative path and its machinery are removed.

4. **The grouping suggestion is rule-based, not AI.** `autoSuggestGroups()` groups by word count
   and memory type — it is not a Claude call. Label it **"We suggest this grouping,"** not "AI
   suggested."

5. **No backward compatibility.** Old chapters are deleted rather than migrated.

6. **Editing scope in the builder:** font family, font size (S/M/L), alignment, bold, italic, and
   content editing on text slots; photo placement; stickers; per-page background. All reuse
   existing components (Tiptap editor, format toolbar, sticker system, photo tray).

## Ideas captured for later (not in S7–S10 scope)

These came up in discussion and are worth revisiting after the builder ships:

- **Decorative auto-population** — surface the AI `title` as a styled page header and `pullQuote`
  as a callout on sparse pages (the fields are already generated and stored, currently underused).
- **Date / week stamps** — a small scrapbook-style badge from each memory's date.
- **Photo presentation styles** — polaroid frame, slight rotation, drop shadow as a per-photo style.
- **Background textures** — subtle paper grain / dot grid beyond solid colors.
- **Sticker auto-suggest** — suggest stickers by memory type/keywords.
- **Re-generation for paged chapters** — refresh AI content while preserving the saved grouping
  (`sourceKeys` + `templateId` per page already give us everything needed).
- **Print-on-demand & shareable link** — deferred features, see `sDeferred-*.md`.
