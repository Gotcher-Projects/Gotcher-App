**Status:** Complete

**Depends on:** S2 (all backend files written and compiling)

## Goal
Verify every S2 backend endpoint works correctly against a live database, upgrade the demo
user to plus tier with credits, and mark S2 complete.

## Pre-flight
1. Start Docker Desktop
2. `cd Backend && ./start-services.sh` (or `docker compose up -d && ./gradlew bootRun`)
3. Confirm the app started and Flyway output shows V24 and V25 applied:
   ```
   Migrating schema "public" to version "24 - create storybook chapters"
   Migrating schema "public" to version "25 - create book share tokens"
   ```
4. Run the seed script (creates / refreshes demo user with plus tier + credits):
   ```bash
   ./seed-demo-user.sh
   ```

## Demo User — Plus Tier
The seed script now runs a psql step at the end to set the demo user to:
- `tier = 'plus'`
- `ai_credits_remaining = 20`
- `credits_reset_at = NOW() + 30 days`

If you need to manually re-apply (e.g. after regenerating chapters burns credits):
```sql
UPDATE users
SET tier = 'plus', ai_credits_remaining = 20, credits_reset_at = NOW() + INTERVAL '30 days'
WHERE email = 'demo@gotcherapp.com';
```

## Verification Steps

### Get a token
```bash
TOKEN=$(curl -sf -X POST http://localhost:3001/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@gotcherapp.com","password":"DemoPass1"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['accessToken'])")
echo $TOKEN
```

### Unlock — event-anchored (milestone)
```bash
curl -sf -X POST http://localhost:3001/storybook/unlock \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"anchorType":"milestone","anchorKey":"4-0","anchorLabel":"Social smiling"}' | python3 -m json.tool
```
Expected: 201, chapter row with `status: "unlocked"`.
Call again → expect same row returned (idempotent, no duplicate).

### Unlock — time-period
```bash
curl -sf -X POST http://localhost:3001/storybook/unlock \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"anchorType":"period","anchorKey":"0-13w","anchorLabel":"Your First Three Months","periodStartWeeks":0,"periodEndWeeks":13}' | python3 -m json.tool
```
Expected: 201, chapter with `period_start_weeks: 0`, `period_end_weeks: 13`.

### List all chapters
```bash
curl -sf http://localhost:3001/storybook \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```
Expected: array containing at least the two chapters just created.

### Generate — get chapter ID first
```bash
CHAPTER_ID=$(curl -sf http://localhost:3001/storybook \
  -H "Authorization: Bearer $TOKEN" \
  | python3 -c "import sys,json; chapters=json.load(sys.stdin); print(chapters[0]['id'])")
echo $CHAPTER_ID
```

### Generate — happy path (costs 1 credit, sets status=draft)
```bash
curl -sf -X POST http://localhost:3001/storybook/generate/$CHAPTER_ID \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```
Expected: 200, `status: "draft"`, `body` contains 2-3 paragraphs of narrative prose.
Check credit decremented: `SELECT ai_credits_remaining FROM users WHERE email='demo@gotcherapp.com';`

### Generate — free user → 403
```bash
# Register a temp free user
curl -sf -X POST http://localhost:3001/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"freetest@test.com","password":"Test1234!","display_name":"Free Tester"}' > /tmp/freereg.json
FREE_TOKEN=$(python3 -c "import json; print(json.load(open('/tmp/freereg.json'))['accessToken'])")

# Unlock a chapter for them
FREE_CHAPTER=$(curl -sf -X POST http://localhost:3001/storybook/unlock \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $FREE_TOKEN" \
  -d '{"anchorType":"milestone","anchorKey":"0-0","anchorLabel":"Turns toward voices"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['id'])")

curl -sf -X POST http://localhost:3001/storybook/generate/$FREE_CHAPTER \
  -H "Authorization: Bearer $FREE_TOKEN"
```
Expected: `{"error":"Upgrade to Plus to generate chapters"}` with HTTP 403.

### Generate — 0 credits → 402

```bash
PGPASSWORD=changeme_local psql -h 127.0.0.1 -U gotcherapp_app -d gotcherapp \

curl -sf -X POST http://localhost:3001/storybook/generate/$CHAPTER_ID \
  -H "Authorization: Bearer $TOKEN"
```
Expected: HTTP 402, `{"error":"No AI credits remaining this month"}`.
Restore credits after: `UPDATE users SET ai_credits_remaining = 20 WHERE email = 'demo@gotcherapp.com';`

### Patch — edit body, publish
```bash
curl -sf -X PATCH http://localhost:3001/storybook/$CHAPTER_ID \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"status":"published"}' | python3 -m json.tool
```
Expected: `status: "published"`, `published_at` is set.

### Delete
```bash
# Unlock a throwaway chapter, then delete it
TEMP_ID=$(curl -sf -X POST http://localhost:3001/storybook/unlock \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"anchorType":"milestone","anchorKey":"8-0","anchorLabel":"Coos and babbles"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['id'])")

curl -sf -X DELETE http://localhost:3001/storybook/$TEMP_ID \
  -H "Authorization: Bearer $TOKEN" -o /dev/null -w "%{http_code}"
```
Expected: 204.

### Share — create and reuse
```bash
curl -sf http://localhost:3001/storybook/share \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
# Call again — should return the same token
curl -sf http://localhost:3001/storybook/share \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```
Expected: same 64-char hex token on both calls.

### Share — free user blocked
```bash
curl -sf http://localhost:3001/storybook/share \
  -H "Authorization: Bearer $FREE_TOKEN"
```
Expected: 403.

### Share — revoke
```bash
curl -sf -X DELETE http://localhost:3001/storybook/share \
  -H "Authorization: Bearer $TOKEN" -o /dev/null -w "%{http_code}"
# New token generated on next GET
curl -sf http://localhost:3001/storybook/share \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```
Expected: DELETE returns 204. GET returns a new (different) token.

### Public endpoint — published chapters
```bash
SHARE_TOKEN=$(curl -sf http://localhost:3001/storybook/share \
  -H "Authorization: Bearer $TOKEN" \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['token'])")

curl -sf http://localhost:3001/book/public/$SHARE_TOKEN | python3 -m json.tool
```
Expected: `{"babyFirstName":"Lily","chapters":[...]}` — only published chapters, no parent info.

### Public endpoint — no auth required
```bash
curl -sf http://localhost:3001/book/public/$SHARE_TOKEN
```
Expected: 200 (no Authorization header needed).

### Public endpoint — unknown token → 404
```bash
curl -sf http://localhost:3001/book/public/notarealtoken -o /dev/null -w "%{http_code}"
```
Expected: 404.
