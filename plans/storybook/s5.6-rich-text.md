## Overview

Replace the plain `<textarea>` text block editor with a **Tiptap**-based rich text editor. Users get bold, italic, font size, and text alignment controls within layout editor text blocks.

Tiptap is recommended over Slate — better React integration, more active maintenance, and simpler API for this use case.

---

## Scope

**In scope:**
- Bold, italic
- Font size (small / normal / large — mapped to fixed px values, not free input)
- Text alignment (left / center / right)
- Paragraph spacing (existing `\n\n` behavior replaced by Tiptap paragraphs)

**Out of scope (post-v1):**
- Underline, strikethrough
- Lists
- Font family switching
- Color per-character

---

## Data Format Change

Currently text blocks store plain string content:
```json
{ "type": "text", "content": "Plain text here..." }
```

With Tiptap, content becomes a ProseMirror JSON doc:
```json
{ "type": "text", "content": { "type": "doc", "content": [...] } }
```

**Backward compat:** At render time, detect whether `content` is a string (legacy) or object (Tiptap JSON). String content renders as plain serif paragraphs (existing behavior). Object content renders via Tiptap's `generateHTML()`.

### LayoutRenderer.jsx
- Add Tiptap HTML generation for object content: `generateHTML(block.content, extensions)`
- Render via `dangerouslySetInnerHTML` with scoped CSS for the rich text styles
- String content: existing paragraph rendering unchanged

## Frontend Changes

### LayoutEditor.jsx — TextBlock

Replace `<textarea>` in edit mode with `<EditorContent>` (Tiptap):

```jsx
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';
import TextAlign from '@tiptap/extension-text-align';

const editor = useEditor({
  extensions: [StarterKit, TextAlign.configure({ types: ['paragraph'] })],
  content: block.content || '',
  onBlur: ({ editor }) => onStopEdit(editor.getJSON()),
});
```

**Formatting toolbar** (visible only when block is in edit mode, rendered above the canvas or inside the block):
- Bold `B`, Italic `I` buttons
- Font size: S / M / L pills
- Alignment: left / center / right icons

### LayoutRenderer.jsx
- `import { generateHTML } from '@tiptap/html'`
- Detect string vs object content, render accordingly
