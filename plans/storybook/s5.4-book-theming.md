## Overview

Two levels of theming:
1. **Book-level theme** — user picks a named preset that sets the default background, font pairing, and accent color for the entire book
2. **Per-page background override** — individual pages can override the background color from a small palette

---

## Theme Presets

3–5 named presets to start. Suggested set:

| Name | Background | Font | Accent |
|---|---|---|---|
| Classic | Cream `#fdf9f2` | Serif | Gold `#9b7e5a` |
| Garden | Sage `#eef4ee` | Rounded sans | Green `#5a8a5a` |
| Dusk | Slate `#f0f0f5` | Sans | Lavender `#7a6aaa` |
| Blush | Soft pink `#fdf0f0` | Serif | Rose `#c47a7a` |

**Question to resolve at implementation time:** Are fonts swapped per theme, or is serif always used?

## Data Model

### Book-level theme
Store on `baby_profiles` — a single theme applies to a baby's whole book.

```sql
-- V32__book_theme.sql
ALTER TABLE baby_profiles ADD COLUMN book_theme VARCHAR(20) NOT NULL DEFAULT 'classic';
```

### Per-page background override
Store in `layout_data` (v2 format) as `backgroundColor` on each page object:
```json
{
  "version": 2,
  "pages": [
    { "id": "page-0", "backgroundColor": "#fdf0f0", "blocks": [...] }
  ]
}
```
No DB change needed — it's inside the existing `layout_data` TEXT column.

## Frontend Changes

### Theme definition file
`Frontend/src/lib/bookThemes.js` — `BOOK_THEMES` array + `getTheme(key)` helper:
```js
export const BOOK_THEMES = [
  { key: 'classic', label: 'Classic', bg: '#fdf9f2', accent: '#9b7e5a', ... },
  ...
];
```

### StorybookTab.jsx
- Add a "Book Theme" picker (small swatch row) at the top of the book tab
- On select: PATCH `/baby-profile/book-theme`
- Pass selected theme down to LayoutRenderer and LayoutEditor

### LayoutRenderer.jsx
- Accept `theme` prop
- Apply `backgroundColor` from the page object (falls back to theme default)
- Apply theme font and accent to text rendering

### LayoutEditor.jsx
- Accept `theme` prop
- Canvas background reflects current page's `backgroundColor` (or theme default)
- Add a small color swatch row in the page nav bar for per-page override
- Swatches: 5 colors from the active theme palette + "default" (inherits theme bg)

---

## Verification

- Pick "Garden" theme → all chapters render with sage background in LayoutRenderer
- In layout editor, override page 2 to Blush → page 2 renders pink, others stay sage
- Switch theme to "Dusk" → all pages update (including page 2's override still applies)
- Classic theme still renders correctly for existing chapters
