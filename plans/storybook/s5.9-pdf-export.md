# S5.9 — Storybook PDF Export ("Download PDF" button)

**Status: Not started**
**Branch:** journal-updates
**Depends on:** S5.45 (portrait 3:4 layout pages, themes, fonts)

---

## Goal

A **Download PDF** button on the Storybook tab that exports the book to a PDF — primarily so the product is easy to share for review (and, longer term, a real keepsake export). It must faithfully reproduce the on-screen pages: theme background, custom fonts, drop caps, photos, and block positions.

---

## Why not reuse the journal `pdf.js` as-is

`Frontend/src/lib/pdf.js` (`generatePdf`/`downloadPdf`) draws journal entries with native jsPDF vector calls. That gives crisp text and tiny files, but it **can't** reproduce the storybook's custom fonts (Playfair/Poppins/etc. — jsPDF core fonts are only Helvetica/Times/Courier), drop caps, theme colors, or the free-form block layout without re-implementing the whole layout engine in millimeters and embedding font files. For a review/keepsake export, visual fidelity matters more than file size.

We will keep `pdf.js` for the journal and add a separate storybook exporter.

---

## Recommended approach — capture + assemble (high fidelity)

Add **`html2canvas`** and pair it with the already-installed **`jspdf`**:

1. New module **`Frontend/src/lib/storybookPdf.js`** exporting `generateStorybookPdf(chapters, theme, babyName)` and reusing the existing **`downloadPdf`** save helper.
2. For each **published** chapter, in book order:
   - **v2 layout chapters:** render each page off-screen at the fixed virtual canvas (`600×800`, the `CANVAS_W/H` from `LayoutRenderer`), `html2canvas` it to a raster, and add it as a full-bleed image to a 3:4 PDF page.
   - **classic (non-layout) chapters:** render the published body (`renderPublishedBody`) into the same off-screen 3:4 frame with the theme background/header, capture, and add as a page (paginating if it overflows).
3. Optional **cover page** first (themed variant of `drawCoverPage` in `pdf.js` — baby name + title), and a small footer page number.
4. `downloadPdf(doc, \`${babyName}-storybook\`)`.

### Off-screen rendering detail
Mount a hidden container (absolute, off-viewport, `width: 600px`, the page's `aspectRatio`) and reuse `LayoutRenderer`'s block math so the capture matches the live page exactly. Ensure web fonts are loaded first via `await document.fonts.ready`, and set `html2canvas` `useCORS: true` (Cloudinary images already serve permissive CORS) with a 2× `scale` for print sharpness.

### Button placement
A `Download PDF` button in the Storybook tab header (near the theme picker) in `StorybookTab.jsx`. Disabled with a spinner while generating; guard the empty-book case. Keep the existing `onError` for failures.
