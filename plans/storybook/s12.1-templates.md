# S12.1 — Template Set Overhaul + Filter Pills

**Status: Not started**
**Branch:** same as S7
**Depends on:** S12 discussion complete (✓)
**Roadmap:** builder-rewrite roadmap; decisions in `s12-templates-photos-polish.md`

---

## Goal

Replace the current 16 templates with a curated 15-template set that has more visual variety and
less filler, and add filter pills to the template picker so users can quickly narrow by page type.

---

## Background

Every template is a set of normalized (0–1) block boxes in `lib/storybookTemplates.js`. The builder
renders thumbnails in `ScrapbookBuilder.jsx` via `TemplateThumb` — a set of absolutely-positioned
divs scaled to 58×77px. The picker (`showTemplatePicker` state, ~line 155–210) is currently a flat
3-column grid with no filtering.

Decisions from S12 discussion:
- 15 proposed templates — see `template-proposals.html` for full visual spec
- Cuts: `gallery`, `memory-gallery`, `three-short`, `two-up-both`
- Adds: `photo-first`, `spotlight`, `l-wrap`, `staggered`
- Filter pills: **1 Memory · Multiple Memories · Photo Only** (+ implicit "All")

---

## Scope

### 1. Replace TEMPLATES in `lib/storybookTemplates.js`

Full replacement of the array. New entries (normalized block coordinates from `template-proposals.html`):

**`photo-first`** — 1 memory, 1 photo
```
photo (0.05, 0.04, 0.90, 0.52)
text  (0.05, 0.60, 0.90, 0.36)
```

**`spotlight`** — 1 memory, 1 photo
```
photo (0.10, 0.06, 0.80, 0.60)
text  (0.12, 0.70, 0.76, 0.22)
```

**`l-wrap`** — 1 memory, 1 photo
```
text  (0.04, 0.04, 0.44, 0.44)   ← top-left arm
photo (0.52, 0.04, 0.44, 0.44)
text  (0.04, 0.52, 0.92, 0.42)   ← continuation (same memory, piece: 'body-continuation' or second text block)
```
Note: both text blocks reference `memoryIndex: 0, piece: 'body'` — the renderer splits the text
across them, or treats the second as overflow. Confirm rendering behaviour at implementation time.

**`staggered`** — 2 memories, 2 photos
```
photo M0 (0.04, 0.04, 0.44, 0.44)
text  M0 (0.04, 0.52, 0.44, 0.44)
text  M1 (0.52, 0.04, 0.44, 0.44)
photo M1 (0.52, 0.52, 0.44, 0.44)
```

Proportions for existing templates that need adjustment:
- `classic`: photo block `height` → 0.52, gap → 0.08 (was 0.02)

### 2. Update `TemplateThumb` in `ScrapbookBuilder.jsx`

`TemplateThumb` currently maps blocks to divs with `left/top/width/height` as percentages.
`l-wrap` has two text blocks that should read as one connected region — add a visual indicator
(e.g. a thin connector line, or just let them render as two blocks at this scale; thumbnail is
58×77px so the gap is ~3px, may not matter). Confirm at implementation time whether it's worth
special-casing.

### 3. Add filter pills to the template picker

Add a `templateFilter` state (`'all' | '1-memory' | 'multi-memory' | 'photo-only'`) above the
template grid. Pills:

| Pill label       | Condition                                    |
|------------------|----------------------------------------------|
| All              | (no filter)                                  |
| 1 Memory         | `t.memoryCount === 1`                        |
| Multiple Memories| `t.memoryCount >= 2`                         |
| Photo Only       | `t.memoryCount === 0`                        |

Filter the `TEMPLATES` array before rendering the grid. Reset filter to `'all'` when the picker
is closed.
