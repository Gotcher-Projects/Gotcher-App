# S5.45 — Layout Real-Estate & Text-Cutoff Fix

**Status: Needs Verification**
**Branch:** journal-updates
**Depends on:** S5.44 (theme cards, 7 fonts, virtual canvas)

---

## Overview

s5.44 made the editor and published view render at the same size, which exposed two deeper problems in "One Page Per Memory" (v2 paged) chapters: the published page wasted most of the card's real estate, and long entries were clipped. Full diagnosis in `storybook-layout-findings.html` (repo root).

Decisions (with the user): shrink the published frame to a book column, trim the header, make header text theme-aware, **and** switch the page from square to portrait (existing test books may be deleted — no migration needed). Fix the cutoff at generation (cap length) with shrink-to-fit as a safety net.

---

## Changes

### Real estate
- **`StorybookTab.jsx`** published `ChapterCard`:
  - Card constrained to `max-w-[560px] mx-auto` so it wraps the page (no wide themed margins).
  - Header trimmed for layout chapters: `pt-10 pb-6` → `pt-6 pb-4`, title `text-2xl` → `text-xl`, divider margin reduced.
  - Header text (TIME PERIOD label, title, date) now uses `theme.textColor` (fallback to existing classes for light themes) — fixes dark-on-dark title on Midnight.

### Portrait page (3:4)
- **`LayoutRenderer.jsx`** and **`LayoutEditor.jsx`**: virtual canvas changed from 500×500 square to **`CANVAS_W=600 × CANVAS_H=800`** (3:4). Container `aspectRatio: '3 / 4'`, blocks positioned by separate width/height dims (`x*CANVAS_W`, `y*CANVAS_H`, …). Renderer container is now full-width (fills the 560px card); editor canvas capped at `max-w-[480px]`. Rnd drag/resize map back through `CANVAS_W`/`CANVAS_H`. Base font = `CANVAS_W*0.025` = 15px.
- Block coordinates are normalized fractions, so this distorts any pre-existing square layouts — acceptable per decision (delete old test books).

### Text cutoff
- **A (cap length):** `ClaudeClient.java` `SINGLE_ENTRY_SYSTEM_PROMPT` now asks for 1–2 short paragraphs / ~60–100 words; `StorybookService.java` `generateSingle` max tokens 400 → 220 (both call sites).
- **B (shrink-to-fit safety net):** new **`Frontend/src/lib/fitText.js`** `useFittedFontSize(ref, baseSize, minSize, deps)` — binary-searches the largest font (down to 8px) that fits the block, measured in unscaled layout px so editor and published agree. Used by `RenderedText` (LayoutRenderer) and `TextBlock` display mode (LayoutEditor).
- **`StorybookWizard.jsx`** `handleGeneratePages`: generated text block height `0.38` → `0.34`, photo `y0.46/h0.50` → `y0.40/h0.56` (more room for the photo now that text is capped + page is taller).
