# S5.5 — Stickers & Decorative Elements

**Status: Complete**
**Branch:** journal-updates
**Depends on:** S5.4 (book theming) or can run after S5.3

---

## Overview

Add a **sticker block type** to the layout editor — small SVG decorations (hearts, stars, footprints, baby icons) that users can drag onto the canvas like any other block. No backend changes needed; stickers are stored as a block type in `layout_data`.

---

## Sticker Set

A static set of SVGs bundled with the frontend. Suggested initial set (~16 stickers):

**Hearts & love:** heart, double heart, heart outline
**Baby:** footprint, onesie, baby bottle, pacifier, star
**Nature:** flower, butterfly, sun, leaf
**Celebration:** balloon, ribbon, sparkle, crown

SVGs live in `Frontend/public/stickers/` as individual `.svg` files, referenced by key.

---

## Data Model

New block type in `layout_data`:
```json
{
  "id": "b-xyz",
  "type": "sticker",
  "stickerKey": "footprint",
  "x": 0.1, "y": 0.1,
  "width": 0.15, "height": 0.15,
  "color": "#9b7e5a"
}
```

`color` is optional — defaults to theme accent. No backend changes; stored in existing `layout_data` column.

---

## Frontend Changes

### Sticker assets
`Frontend/public/stickers/` — SVG files named by key (e.g. `footprint.svg`, `heart.svg`)

`Frontend/src/lib/stickers.js` — `STICKERS` array:
```js
export const STICKERS = [
  { key: 'footprint', label: 'Footprint' },
  { key: 'heart', label: 'Heart' },
  ...
];
```

### LayoutEditor.jsx

**Toolbar:** Add "Add Sticker" button (opens sticker picker)

**StickerPicker component** (similar to PhotoTray — bottom sheet):
- Grid of sticker thumbnails
- On select: add sticker block at center of canvas

**StickerBlock component:**
- Renders `<img src={/stickers/${stickerKey}.svg} />` inside the Rnd container
- No delete button difference from other blocks (existing X button applies)
- Optional: small color dot in corner to cycle through theme accent colors

### LayoutRenderer.jsx
- Handle `block.type === 'sticker'` — render `<img>` at the block's position/size
