My lean: ship Design 1 as the default render and let Design 2's behaviours (sibling row, initial-circle fallback, missing-grandparent slots) be the same renderer reacting to data — not a separate variant. Rendering: inline <svg> for the connector lines + circular avatars (the plan's recommendation). Avoid foreignObject — it doesn't capture in html2canvas, so the page wouldn't export to PDF. Keep all avatars/labels as native SVG <circle>/<text> so screen and PDF match.
