S5.1 Phase B — Testing Instructions

Multi-page chapters, paged mode wizard, and layout editor carousel.

Setup

  • Start the backend on port 3001 and frontend on port 3000
  • Log in with a paid-tier account that has journal entries or first times
  • Open Memories → Book and click Create a Chapter
1

Mode picker appears New

  1. Select a time period that has entries.
  2. On step 2, leave some entries selected and click Continue.
  3. Step 3 shows "How would you like to tell this story?" with two cards — One Story and One Page Per Memory.
  4. Check the One Page Per Memory card — it should show the credit cost based on selected entries, e.g. "Uses 1 credit per page (3 credits)".
2

Single mode still works Regression

  1. On the mode picker, click One Story.
  2. Goes to step 4 — supplementary notes textarea + Generate button.
  3. Generate the chapter and confirm it appears in the review step (step 5) with the chapter body.
  4. Click Design your page to enter the layout editor (step 6).
  5. The Back button returns to step 5 (review), not the mode picker.
  6. Publish the chapter and confirm it appears in the book list.
3

Paged mode — generation New

  1. Start a new chapter. Pick a period with 2–3 entries (ideally a mix of journal entries and first times).
  2. On step 2, add photos to at least one entry if possible.
  3. On step 3, click One Page Per Memory.
  4. Spinner appears: "Writing your pages…" — takes a moment (one Claude call per entry).
  5. After completion, goes directly to the layout editor — no review step.
  6. Confirm the layout editor canvas shows Page 1 of N navigation at the bottom.
  7. Each page should have a text block pre-filled with a short blurb about that specific memory, and a photo block already assigned if that entry had a photo.
4

Multi-page layout editor navigation New

  1. In the layout editor from Test 3, use the < > arrows at the bottom to flip between pages.
  2. Each page shows its own independent blocks. The label in the nav bar shows the entry title, e.g. "First Smile · Page 2 of 3".
  3. Edit the text block on page 1 (double-click or double-tap to enter edit mode), change some text, then click away to save.
  4. Switch to page 2. Switch back to page 1.
  5. Your edited text is still there. Page 2 is unchanged.
  6. Drag a block to a new position — wait for "Saving…" → "Saved ✓" to appear in the toolbar.
  7. Click Add Page in the toolbar.
  8. A new blank page is added and you land on it. The nav shows the updated page count.
  9. Publish the chapter — confirm it saves successfully.
5

Published chapter carousel New

  1. After publishing in Test 3 or 4, find the chapter in the book list.
  2. The chapter card shows a canvas with < 1 / N > arrows below it.
  3. Click the arrows to flip through pages — each page renders its layout correctly.
  4. On mobile: swipe left/right on the canvas to advance pages.
  5. Confirm an older single-page (v1) chapter still renders normally with no arrows.
6

Credit deduction New

  1. Note your current credit count before starting.
  2. Run paged mode with 3 entries selected.
  3. After generation completes, your credits have decreased by 3.
  4. Optional: if you can set credits to 1 in the DB, try paged mode with 3 entries — expect an error: "Not enough credits — 1 credit is used per page".
7

Photo drag/click fix Regression

  1. Open any existing chapter's layout editor (click Design on an existing draft).
  2. If a photo block has an image, try dragging it across the canvas.
  3. Block drags freely — the photo swap tray does not open.
  4. Now tap/click the small Camera icon in the top-right corner of the photo block.
  5. The photo swap tray opens.
  6. For an empty photo block (dashed border), clicking anywhere on it should still open the tray.

Things to watch for

  • If the API key isn't configured, paged mode will error — check the toast message.
  • If credits run out mid-generation, all used credits should be refunded and an error shown.
  • The Back button in the layout editor for paged mode goes to the mode picker (step 3). For single mode it goes to the review step (step 5).
  • Existing single-page (v1) chapters must still open in the layout editor with no regressions.
  • The step counter in the wizard header shows "Step 1 of 3", "Step 2 of 3", "Step 3 of 3" for the wizard steps, then just "Create a Chapter" for the layout editor.
