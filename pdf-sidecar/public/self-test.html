pr1 — proves the headless-Chrome → PDF mechanism offline

This page exists to prove, in a generated PDF, the four things pr1 must demonstrate. It is not a real book page — that arrives with the pr2 print-view route. Open the PDF this renders to and confirm each item below.

  • Vector text — select this paragraph in the PDF; it should be real, crisp text at any zoom, not a rasterized image of text.
  • Embedded fonts — this body is a serif, the headings a sans; both must render and be embedded (check the PDF's font list).
  • Colored backgrounds — the pink→indigo page wash and the swatches below only appear if printBackground is honoured.
  • Native-res raster image — the 900×1200 sample below should stay sharp when you zoom the PDF (it is embedded at native resolution, not down-sampled to a page raster).
